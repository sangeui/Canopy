## 무엇이 바뀌었나요

### 주요 기능 및 추가
- **앱 내 자동 업데이트 및 릴리즈 노트 뷰어**: 앱을 실행할 때 GitHub Releases의 새 버전을 자동으로 확인하고, 하단 상태 표시줄 배너와 **Canopy › 업데이트 확인…** 메뉴에서 마크다운 릴리즈 노트를 읽은 뒤 원클릭으로 다운로드·SHA-256 및 서명 검증·설치·재실행합니다.
- **터미널 한 줄 설치 스크립트 (`scripts/install.sh`)**: 최신 Universal DMG 다운로드, SHA-256 체크섬 검증, `/Applications/Canopy.app` 설치, Gatekeeper 격리 속성(`xattr -cr`) 해제를 한 줄 명령으로 자동화했습니다.
- **합치기 전 실시간 충돌 미리보기 (`git merge-tree`)**: 브랜치 비교 헤더와 머지·리베이스·리버트·풀 확인 창에서 실제로 합치기 전에 충돌할 파일 목록과 충돌 구간을 미리 계산해 보여 줍니다.
- **워크트리 인식 `⌘Z` / `⇧⌘Z` 실행 취소**: 커밋, 파일·줄 버리기, 체크아웃, 머지·리베이스·체리픽·리버트, 스태시, 브랜치·태그 작업을 워크트리별 캐시 스냅샷으로 0.05~0.15초 안에 기록하고 그 작업이 바꾼 파일만 정밀하게 복원합니다.

### 개선 및 사용성
- **선언 이름 & 낱말 단위 Diff (`NSTextView`)**: 바뀐 선언(`func` / `class` / `var`)을 파일 및 hunk 머리말에 표시하고, 삭제·추가된 줄 사이에서 실제로 바뀐 단어만 강조하며 드래그한 줄만 부분 스테이징·버리기합니다.
- **APFS DMG 패키징 및 번들 경량화**: 최신 macOS에서 경고 없이 마운트되도록 DMG 파일 시스템을 APFS로 전환하고, 중복 리소스를 정리하여 앱 번들 크기를 약 3.8MB 줄였습니다.
- **Claude Code · Antigravity 듀얼 어시스턴트 지원 (`⌘I`)**: 설정(`⌘,`)이나 어시스턴트 카드 상단에서 **Claude**와 **Antigravity (`agy` / `gemini`)** 중 원하는 엔진을 직접 선택할 수 있으며, 각 엔진의 로컬 스킬(`.claude/skills`, `.agents/skills`, `.gemini/skills`) 자동완성과 최소 권한 읽기 격리(`--approval-mode plan` / `--sandbox`)를 지원합니다.
- **어시스턴트 마크 벡터 렌더링**: 비트맵 이미지 대신 SwiftUI `Canvas` 벡터 그래픽으로 Claude와 Antigravity 마크를 모든 해상도와 테마에서 선명하게 그립니다.
